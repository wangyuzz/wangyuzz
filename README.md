### [TodaEat · 今天吃什么](https://github.com/wangyuzz/TodaEat)

A self-hosted restaurant wishlist and shared dining journal for two people. Save places to try, pick a restaurant when you cannot decide, and record meals, ratings, moods, and photos.

一个可自行部署的餐厅收藏与双人用餐手账：收藏想去的店，随机决定去哪吃，记录每一餐的评分、心情和照片。

Built with **React + Vite, Go + Gin, and SQLite**. Includes a photo wall, achievements, separate application and administrator access, English / Chinese documentation, and Windows / Linux downloads.

### [agent-session-cleaner](https://github.com/wangyuzz/agent-session-cleaner)

在一个终端里浏览、恢复和整理 Codex、Claude Code、OpenCode、Pi 与 Grok 的会话，并将对话预览导出为 Markdown。

A terminal application for browsing, resuming, organizing, and exporting AI agent sessions across Windows, macOS, and Linux.

| 关注方向 · Focus | 我的改进 · Contributions |
| --- | --- |
| Windows 体验 | Codex 命令性能优化、原生快捷键与 PowerShell 更新兼容 |
| 会话管理 | Grok 会话支持、恢复命令复制与 Markdown 导出 |
| 导出可靠性 | 自定义目录、并发防覆盖、失败清理与跨平台文件名处理 |
| 可维护性 | 回归测试、中英文说明与贡献指南 |

这是我维护的 MIT 许可 Fork，基于 [haowang02/agent-session-cleaner](https://github.com/haowang02/agent-session-cleaner)。感谢原作者的工作；我的维护与新增功能可以在提交记录中查看。

I maintain this MIT-licensed fork of the original project, with improvements to Windows usability, Grok support, and reliable session exports.
